# RAxML sources

This directory targets the complete official documentation for
**standard-RAxML 8.2.x**.

- `raxml_v8.2.x_manual.pdf` is the official manual downloaded from the official
  standard-RAxML repository/source URL.
- `extracted_contract_candidate.json` contains traceable candidate facts extracted
  from primary sources. It is not approved operational knowledge.

RAxML-NG is a distinct implementation and must receive its own version-scoped
source record before its contracts are used.
